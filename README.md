# On Time

On Time är en mobilapp som jag arbetade med under min LIA. Tanken med appen var att göra det enklare att planera möten, bjuda in deltagare och hålla koll på vilka som kommer att delta.

## Funktionalitet

- Inloggning och registrering
- Skapa och hantera möten
- Bjuda in deltagare
- Hantera mötesinbjudningar
- Visa deltagarnas status
- Pushnotiser via Firebase

## Teknik

- Flutter
- Dart
- C# och .NET
- ASP.NET Core Web API
- Entity Framework Core
- Firebase

## Projektstatus

Projektet påbörjades under min LIA men blev inte helt färdigställt. Vissa funktioner behöver fortfarande vidareutvecklas.
